# Источники и проверка

Проверено 15 сентября 2026 года прямыми HTTP-запросами из среды разработки. Это фиксация проверки, а не гарантия будущей доступности: сайты могут менять структуру, блокировать серверы и закрывать вакансии.

## Приоритет 1 — Сайты работодателей

| Компания | Каталог | Реализация и результат |
|---|---|---|
| Яндекс | [Яндекс Карьера](https://yandex.ru/jobs/vacancies) | Работает. Профессии product-manager, project-manager, tech-manager; сериализованные данные публичной страницы; курсорная пагинация. Поле modified не считается датой публикации. |
| VK | [VK Team](https://team.vk.company/vacancy/) | Работает. Публичный `/career/api/v2/vacancies/`, limit/offset, проверка count. Дата публикации в краткой выдаче отсутствует. |
| Сбер | [Сбер Карьера](https://rabota.sber.ru/search/) | Работает. Публичные profAreas и publications карьерного сайта; категории продуктовых/проектных ролей плюс запросы «продакт», product, project. Использует skip/take и total. Поиск по фразе слишком широкий, поэтому не используется как основной. |
| Т-Банк | [Т-Банк Карьера](https://www.tbank.ru/career/vacancies/it/) | Работает. Публичный метод getVacancies, категории tcareer_it и tcareer_back_office; последовательная пагинация. POST используется только для чтения каталога. UUID определяет вакансию; город в пути ссылки служит контекстом навигации, город в отчете берется из карточки. |
| Авито | [Авито Карьера](https://career.avito.com/vacancies/) | Работает. Карточки публичной HTML-страницы с прямыми ссылками, городом и форматом. В проверенной странице все карточки присутствовали в HTML. При обнаружении дополнительной пагинации статус станет частичным. |
| МТС | [МТС Карьера](https://job.mts.ru/vacancies) | Работает. Публичный `/api/v2/vacancies`, pagination[page]/pagination[pageSize], pageCount. Для ссылки используется строковый slug, не округленный числовой id. |
| Ozon | [Ozon Карьера](https://job.ozon.ru/vacancy/) | HTTP 403. Реализована диагностика, полноценный парсер прямого каталога пока не реализован. Возможен сбор компании через площадки. |
| Wildberries / RWB | [RWB Карьера](https://career.rwb.ru/vacancies) | Главная страница открывается, публичный каталог `/crm-api/api/v1/pub/vacancies` возвращает HTTP 403. Реализована диагностика; парсер требует доступных ответов для разработки. Возможен сбор компании через площадки. |

## Приоритет 2 — Площадки

| Площадка | Каталог | Реализация и результат |
|---|---|---|
| Getmatch | [Вакансии](https://getmatch.ru/vacancies) | Работает. Публичный `/api/offers`; offset увеличивается на meta.limit, поскольку площадка может вставить дополнительные промо-карточки. Проверяются активность, точное имя компании и ограничения локации. Скрытая/оценочная зарплата не выводится. |
| Хабр Карьера | [Вакансии](https://career.habr.com/vacancies) | Работает. Публичные страницы поиска, встроенный JSON и ссылки пагинации. Пропуски locations/qualification/salary поддерживаются. Поле predictedSalary не используется. |

## Приоритет 3 — hh.ru

[Официальный API](https://api.hh.ru/openapi/redoc). По умолчанию выключен; команда `/hh on` включает его дополнительно. В данной среде live-запрос получил 403. Логика пагинации, запроса и ошибок проверяется без сети; реальная доступность зависит от сервера и настроек клиента. В `config.py` используются явные employer_id основных профилей, не поиск работодателя по подстроке.

## Методология и ограничения

- Успех проверки означает, что адаптер получил доступную выдачу и завершил реализованную пагинацию. Это не означает, что сайт публикует здесь все вакансии всей группы компаний.
- Word содержит статус источника, а не общий безусловный «сбор успешен».
- Для Яндекса, VK, Авито и Т-Банка краткая выдача не дает надежной даты публикации. Они попадают в отдельный раздел по дате первого обнаружения ботом.
- Дата Getmatch без часового пояса нормализуется в UTC; в отчете показывается только календарная дата. На границах суточного периода возможна небольшая разница с часовым поясом площадки.
- Локальные тесты: 41 проверка. Установка пакета и согласованность зависимостей проверены. Образ Docker подготовлен, сборка контейнера в этой среде не выполнялась.
- Пример Word проверен через рендер всех его страниц. Кликабельность ссылок проверена в структуре DOCX; несколько реальных ссылок Сбера, Т-Банка и Хабр Карьеры проверены HTTP-запросами.
- Реальные отправки в Telegram и доставка по расписанию требуют пользовательского токена и работающего сервера. Здесь они не выполнялись; обработчики и сохранение расписания проверены локальными тестами.

## Как добавить источник

Наследуйте Adapter из `vacancy_bot/sources/common.py`, задайте name/url и key для компании (или None для площадки), реализуйте collect(), передавайте записи через make()/add(). Зарегистрируйте класс в ADAPTERS. Нужны проверки реальной схемы, всей пагинации, закрытых вакансий, дат, региона и ошибок; отсутствие карточек в неожиданной схеме не должно считаться успешной пустой выдачей. Для недоступного сайта сохраняйте статус ошибки и документируйте ограничение.
