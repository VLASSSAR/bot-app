# План реализации

## Цель

Telegram-бот на Python собирает вакансии продуктового менеджера, проектного менеджера и технического продакт-менеджера в российском бигтехе. Основной источник — карьерные сайты работодателей, затем Getmatch и Хабр Карьера. hh.ru подключается по желанию. Результат — Word-файл с прямыми ссылками.

## Этап 1 — Первая работающая версия

1. Проверить публичные каталоги восьми компаний и площадок, установить доступные способы загрузки и пагинации.
2. Реализовать отдельные адаптеры, единую карточку вакансии и явный статус каждого источника.
3. Добавить русские и английские варианты названий ролей, географию, период, удаленную работу и список компаний.
4. Объединять точные межсайтовые повторы, сохраняя приоритет сайта работодателя и все ссылки.
5. Хранить первую дату обнаружения отдельно от даты публикации; явно обозначать неизвестные поля.
6. Формировать Word-отчет с разделами по известности дат и состоянию источников.
7. Реализовать Telegram-команды и ежедневную подписку, хранить настройки в SQLite.
8. Проверить обработку сбоев, пагинацию, доступ пользователей и документ; подготовить Docker и CI.

Этап реализован для доступных источников. Прямые Ozon и RWB остаются заблокированы HTTP 403; в отчете это отражается. Требуется отдельная проверка Telegram с токеном пользователя и развертывание на его сервере.

## Этап 2 — Расширить прямой охват

- Подключить прямые Ozon и RWB, когда будет доступен разрешенный публичный каталог/API или экспорт; проверить формат на реальных ответах.
- Расширить справочник проверенных дочерних брендов: отдельные направления Ozon, Сбера, Яндекса, МТС и VK.
- По запросу подключить дополнительные площадки или конкретные публичные карьерные Telegram-каналы. Для каналов нужен отдельный способ чтения; Telegram Bot API не дает произвольную историю чужих каналов.
- Уточнить географию для всех городов и региональных ограничений удаленной работы, не предполагая ее по бренду компании.
- Расширить словарь ролей по реальным пропускам, сохраняя контроль ложных совпадений.

## Этап 3 — Улучшить мониторинг

- Рассылка только новых вакансий и уведомления об изменениях.
- Отдельный плановый сбор и очередь отчетов при росте числа пользователей.
- История изменений вакансий, повторная проверка закрытых карточек, показатели доступности источников.
- Дополнительные пользовательские фильтры: грейд, зарплата, опыт, конкретный город.

## Критерии готовности к личному использованию

- Все автоматические тесты проходят; Word открывается и содержит рабочие внешние ссылки.
- Отчет не скрывает недоступность/частичную выдачу источников.
- Настройки и ежедневная подписка сохраняются после перезапуска.
- Пользователь внес токен и свой ID, проверил `/report` в Telegram.
- Процесс запущен на постоянно работающем сервере; его доступ к источникам проверен.
