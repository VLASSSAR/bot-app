# Вакансии российского бигтеха в Telegram

Python-бот собирает вакансии продуктовых, проектных и технических продакт-менеджеров и отправляет Word-файл с кликабельными ссылками.

**Приоритет источников: карьерные сайты компаний → Getmatch и Хабр Карьера → hh.ru.** hh.ru по умолчанию выключен. Основные источники работают без аккаунта на площадках; вакансии за авторизацией не собираются.

Компании: Яндекс, VK, Сбер, Т-Банк, Ozon, Wildberries/RWB, Авито и МТС. По умолчанию — 30 дней, все форматы работы. На площадках применяются точные названия компаний и явно заданные алиасы: объявления кадровых агентств и анонимные работодатели исключаются.

## Что входит в первую версию

- Поиск русских и английских названий трех ролей, включая Product Owner.
- Прямые ссылки, компания, город, формат работы, зарплата и опыт, если источник их сообщает.
- Отдельные разделы для вакансий с датой публикации и без неё.
- Осторожное объединение одинаковых публикаций между источниками с приоритетом сайта компании и сохранением дополнительных ссылок.
- Word-отчет по запросу и ежедневная подписка; настройки сохраняются в SQLite.
- Статус каждого источника в отчете: проверен, частично или недоступен.
- Повторные запросы при временных сбоях, ограничение времени сбора и кеш на 15 минут.
- Доступ только разрешенным Telegram-пользователям в личном чате.

**Текущее ограничение:** прямые сайты Ozon и RWB возвращают HTTP 403 из среды проверки. Для них пока предусмотрены диагностика и явный статус недоступности, полноценные парсеры не реализованы без возможности проверить ответы. Вакансии этих компаний могут попадать из Getmatch, Хабр Карьеры и при включении hh.ru. Полнота группы компаний зависит от набора алиасов/профилей. Проверка источников описана в [docs/SOURCES.md](docs/SOURCES.md).

## Быстрый запуск

Нужен Python 3.11 или новее. Рекомендуется Python 3.12.

```bash
git clone https://github.com/VLASSSAR/bot-app.git
cd bot-app
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
cp .env.example .env
```

1. Создайте бота командой `/newbot` у официального [@BotFather](https://t.me/BotFather).
2. Впишите токен в `TELEGRAM_BOT_TOKEN` в локальном `.env`. Не публикуйте токен в GitHub или переписке.
3. Запустите `python -m vacancy_bot`. Отправьте боту `/whoami`.
4. Укажите полученный ID в `ALLOWED_USER_IDS` в `.env` и перезапустите процесс. Несколько ID разделяются запятыми. Пока список пуст, доступна только команда `/whoami`.
5. Отправьте `/start`, затем `/report`. Первый сбор занимает несколько минут. Повторный запрос в течение 15 минут использует общий кеш.

На Windows активация окружения: `.venv\Scripts\activate`.

Переменные окружения процесса имеют приоритет над `.env`.

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен BotFather |
| `ALLOWED_USER_IDS` | Разрешенные числовые ID пользователей |
| `HTTP_USER_AGENT` | Идентификация сборщика, желательно с вашим контактом |
| `HH_ACCESS_TOKEN` | Необязательный токен приложения hh.ru |
| `DATABASE_PATH` | Путь SQLite, по умолчанию `data/bot.sqlite3` |
| `BOT_TIMEZONE` | Часовой пояс рассылки, по умолчанию `Asia/Novosibirsk` |

Для первого запуска бот использует long polling: внешний HTTPS-сервер и открытые входящие порты не нужны. Не запускайте два экземпляра с одним Telegram-токеном.

## Команды

| Команда | Действие |
|---|---|
| `/report` | Отчет Word с текущими фильтрами |
| `/period 7` | Последние 7 дней, допустимо 1–30 |
| `/remote on` / `/remote off` | Только удаленно / все форматы |
| `/companies` | Список ключей компаний |
| `/companies yandex vk sber` | Выбрать компании |
| `/companies all` | Все восемь компаний |
| `/hh on` / `/hh off` | Включить / отключить дополнительный поиск hh.ru |
| `/subscribe 09:00` | Ежедневный отчет в 09:00 в часовом поясе бота |
| `/unsubscribe` | Отключить рассылку |
| `/settings` | Посмотреть фильтры и подписку |
| `/whoami` | Узнать свой Telegram ID |
| `/help` | Справка |

Подписка отправляет полную подборку по текущим фильтрам, включая дни без новых вакансий. Она восстанавливается после перезапуска. Пропущенные во время выключения сервера дни не рассылаются задним числом. Если пользователь заблокировал бота, подписка отключается.

## Как читать отчет

- **Дата публикации** берется только из соответствующего поля источника. Поле изменения карточки не заменяет ее.
- **Впервые найдена** — дата первого успешного обнаружения ботом, сохраняется в SQLite. При первом запуске вакансии без даты могут быть старыми. После 30 дней с первого обнаружения они перестают попадать в отчет с таким периодом.
- Явно иностранные вакансии исключаются. Если сайт не указал город/страну либо город не распознан, вакансия остается с пометкой «возможность работы из России не подтверждена». Getmatch проверяется по ограничениям локации, включая исключение России из удаленной работы.
- При `/remote on` требуется явный признак удаленной работы у источника; гибрид сам по себе не считается удаленкой.
- Прогноз зарплаты площадки и скрытые суммы не выдаются за зарплату работодателя.
- Сходство названий не доказывает дубликат. Объединяются точные нормализованные совпадения компании, названия и города между источниками. Если на одном сайте несколько таких карточек, они остаются раздельными.
- Если один источник недоступен, остальные продолжают работу. Отчет раскрывает ограничения; полное падение источников возвращает ошибку, а не «вакансий нет».

## Отчет без Telegram

```bash
python -m vacancy_bot --report output/vacancies.docx
```

Токен Telegram не требуется. Используются стандартные фильтры (30 дней, все компании, hh.ru выключен). Для формирования DOCX нужен только `python-docx`; Microsoft Word и LibreOffice на сервере не требуются.

## Запуск через Docker

Заполните `.env`, затем:

```bash
docker compose up -d --build
docker compose logs -f
```

Контейнер автоматически перезапускается, база хранится в именованном томе. Для круглосуточной работы нужен постоянно включенный сервер с доступом к Telegram и источникам. Код подготовлен к развертыванию; сервер и действующий токен не входят в репозиторий.

Остановка без удаления базы:

```bash
docker compose down
```

После смены `.env`: `docker compose up -d --force-recreate`. Не используйте `down -v`, если нужно сохранить настройки и историю обнаружения.

## Разработка и проверки

```bash
python -m pip install -e '.[dev]'
ruff check vacancy_bot tests
ruff format --check vacancy_bot tests
pytest -q
```

Тесты работают без сети и секретов: проверяют пагинацию, сбои источников, фильтры, ссылки Word, SQLite и команды. Живая проверка требует отдельного запуска `--report`. Ее результаты и ограничения зафиксированы в `docs/SOURCES.md`. CI выполняет тесты на Python 3.11 и 3.12.

Структура:

- `vacancy_bot/sources/` — отдельные адаптеры карьерных сайтов и площадок;
- `vacancy_bot/hh.py` — дополнительный адаптер hh.ru;
- `vacancy_bot/service.py` — сбор, фильтры, кеш, объединение публикаций;
- `vacancy_bot/storage.py` — настройки, подписки и первая дата обнаружения;
- `vacancy_bot/report.py` — создание Word-файла;
- `vacancy_bot/bot.py` — команды и рассылка;
- `docs/PLAN.md` — план реализации и следующие этапы.

Публичные методы фронтендов могут меняться без предупреждения. Адаптеры не обходят CAPTCHA/авторизацию; изменения структуры и отказы доступа отображаются как ограничения источников.
